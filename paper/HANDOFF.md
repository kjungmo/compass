## 1. 프로젝트 개요

- **도메인:** 모바일 서비스 로봇(서빙·배송·안내)의 로컬 경로 계획. ROS2/`Nav2` 플러그인으로 구현 예정.
- **문제:** 혼잡 보행 환경에서 로컬 플래너가 좌/우 통과 방향을 매 주기 탐욕적으로 재선택하다 진동(우왕좌왕)하거나 얼어붙음(freezing).
- **핵심 기여:** 통과 결정의 **시간 일관성(temporal commitment)** 을 1급 목표로 두는 결정 계층 설계. 누수 증거 누적 기반 커밋 + 안전 사전식 오버라이드 + `class` 정체 안정화.
- **계층 구분:** ① 결정·행동(본 논문) / ② 궤적 생성(기존 채택) / ③ 표현(FSD식 AR 오버레이, 데모).

## 4. 확정된 핵심 설계 (재논의 불필요)

### 4.1 예측
칼만-등속(constant-velocity Kalman). 사람 i에 대해 평균 `p̂_i(t)`와 공분산 `Σ_i(t)`(지평선 길수록 증가). 결정용으로 충분하며 과투자 금지. 학습 기반 예측기(Social-LSTM/Trajectron++ 류)는 교체 가능한 입력 모듈로 결합 가능.

### 4.2 위상 class 표현·대응
- 라벨: 관련자 K명(1~3)에 대한 좌/우 부호 벡터 `c = (s_id1, …, s_idK)`, `s∈{L,R}`. 정체를 **track ID에 묶음**.
- 가용성 가지치기: 통로 폭 < 로봇 폭 + 여유 → `J = ∞` (원형 풋프린트 근사 전제; 직사각형은 §6에서 보수화).
- 생애주기: 생성(새 도전자, e=0)/소멸(흡수)/병합(거친 class)/분할(로봇 오프셋 정합 자식)/일시 비가용(TTL로 정체 기억).
- 앞/뒤는 별도 class가 아니라 §4.3 비대칭 비용으로 처리.

### 4.3 비용 함수 (정규화 후 가중합)
`J(c) = w_g·J_goal + w_s·J_social + w_e·J_effort + w_r·J_rule`  (비가용 ⇒ ∞)
- `J_social = Σ_i ∫₀ᵀ exp(−½ δᵀ M_i(t)⁻¹ δ) dt`,  `δ = p_r(t) − p̂_i(t)`
- `M_i(t) = R_i·diag(σ_h², σ_s²)·R_iᵀ + Σ_i(t)`  (σ_h: 앞이면 σ_front, 뒤면 σ_rear<σ_front)
- `J_effort = ∫₀ᵀ (α κ² + β a² + γ κ̇²) dt`  (κ̇ 항이 G2 연속 유도)
- `J_rule`: 통행 관습(우측 선호; **로캘 설정값**, 보편 상수 아님)·차선 유지 소프트 벌점
하드 가용성(별도): 정적 충돌 / 통로 폭 / 운동학 한계 / 하드 안전거리 `d_safe`.

### 4.4 커밋 전환 규칙 (헤드라인) — v0.4 분리 누적기
도전자 `c′ = argmin_{c≠c*} J(c)`, 도전자 우위 `D_k = J(c*) − J(c′)`.
- 통합식 직관(분리 전): `e_k = clip(λ·e_{k−1} + (D_k − Δ_floor)·dt, 0, e_max)`, 전환 if `e_k ≥ E_th(ρ)`.
- **분리(정본):** 도전 누적은 역방향 `e^rev`로 적분하고 `e^rev ≥ E_th(ρ)`에서 전환; 현재 class 고정 헤드룸은 정방향 `e^fwd`(상한 `e_max^fwd > E_0(1+k_ρ)`)로 보장. 봉쇄 조건은 `E_th(ρ̄) > e^rev_max`에만 부과.
- `E_th(ρ) = E_0·(1 + k_ρ·ρ^p)` (p≥1), `ρ = clip(실행 횡오프셋 / 계획 횡오프셋, 0, 1)`.
- `Δ_floor`=마진(히스테리시스), `E_th`=드웰(지속), `k_ρ ρ^p`=진행 경화(복귀 불가점).
- 비공허성: `e^rev_max > E_0`여야 재량 전환이 애초에 가능. `λ<1`이면 도달 상한 `e^rev_max = min(e_max, (D_max−Δ_floor)dt/(1−λ))`.
- 타이브레이크: 직전 c′ 우선(ε 경계 히스테리시스 ε_in<ε_out) → c*와의 위상 거리 → 결정적 사전순.
- 리셋: c′ 변경 시 e←0; 전환·커밋 시 e←0, ρ←0.

### 4.5 안전 오버라이드 (사전식 최상위)
`Safe(c) = clearance≥d_safe ∧ TTC≥TTC_min ∧ feasible`. `c* ∉ 𝒮` ⇒ 누적·경화 무시, 사다리: ① 안전 대안 전환 → ② 감속 → ③ 정지·양보. 스래시 가드: 창 W 내 안전 유발 전환 N_thrash회 ⇒ HOLD.

### 4.6 속성
P1 반진동(D_k 평균0·유계분산 가정의 **기대 전환율 상한**, θ*≈2·Δ_floor/(σ_D²·dt)) · P2 전환율 상한 · P3 안전 지배 · P4 기동 완수(ρ 동역학 + 횡 진행률 하한 v_lat,min, 역방향 누적기 봉쇄) · P5 교착 탈출. (정본 증명은 paper_draft.md §4.6.)

### 4.7 노브 목록 (= ablation 축)
Δ_floor, E_0, k_ρ, p, λ, e_max^fwd/e_max^rev · d_safe, TTC_min · W, N_thrash · w_g/w_s/w_e/w_r · σ_front/σ_rear/σ_s · K(관련자 수) · K_cap.

### 4.8 구현
`Nav2` 커스텀 컨트롤러(또는 플래너) 플러그인. gap←costmap/laser, track·ID←사람 추적 노드. 주기 간 상태(라벨·e^fwd·e^rev·ρ·TTL)는 플러그인 멤버로 보존. F-formation 검출은 외부 인지 모듈 가정.
