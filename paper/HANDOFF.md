## 0. 한 줄 요약 · 재개 지점

서비스 로봇의 **사회적 경로 결정 플래너**(통과 결정의 시간 일관성 = 반진동) 논문. 초안은 **v0.5(텍스트 완료)** 이며, 모사 동료 심사 4라운드(저자 + 심사 A·B·C + 편집자)를 거쳐 편집자 `textComplete=true`로 수렴했습니다.
**재개 지점 = 실험(R1~R4·O1) — 시뮬레이터 구축 → `src/` 구현 → 측정값으로 `[TBD]` 교체.** 텍스트로 가능한 개정(R5·R6·O2·O3·O4 및 R1~R4의 프레이밍)은 모두 완료되었습니다.

> **v0.4 정형 정정 주의:** 단일 누수 누적기 `e_k`는 v0.4에서 **정방향 `e^fwd`(현재 class 고정)** 와 **역방향 `e^rev`(도전 class 누적)** 두 개로 분리되었습니다(P4 봉쇄 vs O4 헤드룸 자기모순 해소). 최신·정본 사양은 항상 `paper_draft.md`(v0.5)입니다. 아래 §4.4는 분리 이전의 통합식 직관을 보존하되, 구현은 v0.5의 분리 누적기를 따릅니다.

## 1. 프로젝트 개요

- **도메인:** 모바일 서비스 로봇(서빙·배송·안내)의 로컬 경로 계획. ROS2/`Nav2` 플러그인으로 구현 예정.
- **문제:** 혼잡 보행 환경에서 로컬 플래너가 좌/우 통과 방향을 매 주기 탐욕적으로 재선택하다 진동(우왕좌왕)하거나 얼어붙음(freezing).
- **핵심 기여:** 통과 결정의 **시간 일관성(temporal commitment)** 을 1급 목표로 두는 결정 계층 설계. 누수 증거 누적 기반 커밋 + 안전 사전식 오버라이드 + `class` 정체 안정화.
- **계층 구분:** ① 결정·행동(본 논문) / ② 궤적 생성(기존 채택) / ③ 표현(FSD식 AR 오버레이, 데모).

## 4. 확정된 핵심 설계 (재논의 불필요)

### 4.1 예측
칼만-등속(constant-velocity Kalman). 사람 i에 대해 평균 `p̂_i(t)`와 공분산 `Σ_i(t)`(지평선 길수록 증가). 결정용으로 충분하며 과투자 금지. 학습 기반 예측기(Social-LSTM/Trajectron++ 류)는 교체 가능한 입력 모듈로 결합 가능.

### 4.2 위상 class 표현·대응
- 라벨: 관련자 K명(1~3)에 대한 좌/우 부호 벡터 `c = (s_id1, …, s_idK)`, `s∈{L,R}`. 정체를 **track ID에 묶음**.
- 가용성 가지치기: 통로 폭 < 로봇 폭 + 여유 → `J = ∞` (원형 풋프린트 근사 전제; 직사각형은 §6에서 보수화).
- 생애주기: 생성(새 도전자, e=0)/소멸(흡수)/병합(거친 class)/분할(로봇 오프셋 정합 자식)/일시 비가용(TTL로 정체 기억).
- 앞/뒤는 별도 class가 아니라 §4.3 비대칭 비용으로 처리.

### 4.3 비용 함수 (정규화 후 가중합)
`J(c) = w_g·J_goal + w_s·J_social + w_e·J_effort + w_r·J_rule`  (비가용 ⇒ ∞)
- `J_social = Σ_i ∫₀ᵀ exp(−½ δᵀ M_i(t)⁻¹ δ) dt`,  `δ = p_r(t) − p̂_i(t)`
- `M_i(t) = R_i·diag(σ_h², σ_s²)·R_iᵀ + Σ_i(t)`  (σ_h: 앞이면 σ_front, 뒤면 σ_rear<σ_front)
- `J_effort = ∫₀ᵀ (α κ² + β a² + γ κ̇²) dt`  (κ̇ 항이 G2 연속 유도)
- `J_rule`: 통행 관습(우측 선호; **로캘 설정값**, 보편 상수 아님)·차선 유지 소프트 벌점
하드 가용성(별도): 정적 충돌 / 통로 폭 / 운동학 한계 / 하드 안전거리 `d_safe`.

### 4.4 커밋 전환 규칙 (헤드라인) — v0.4 분리 누적기
도전자 `c′ = argmin_{c≠c*} J(c)`, 도전자 우위 `D_k = J(c*) − J(c′)`.
- 통합식 직관(분리 전): `e_k = clip(λ·e_{k−1} + (D_k − Δ_floor)·dt, 0, e_max)`, 전환 if `e_k ≥ E_th(ρ)`.
- **분리(정본):** 도전 누적은 역방향 `e^rev`로 적분하고 `e^rev ≥ E_th(ρ)`에서 전환; 현재 class 고정 헤드룸은 정방향 `e^fwd`(상한 `e_max^fwd > E_0(1+k_ρ)`)로 보장. 봉쇄 조건은 `E_th(ρ̄) > e^rev_max`에만 부과.
- `E_th(ρ) = E_0·(1 + k_ρ·ρ^p)` (p≥1), `ρ = clip(실행 횡오프셋 / 계획 횡오프셋, 0, 1)`.
- `Δ_floor`=마진(히스테리시스), `E_th`=드웰(지속), `k_ρ ρ^p`=진행 경화(복귀 불가점).
- 비공허성: `e^rev_max > E_0`여야 재량 전환이 애초에 가능. `λ<1`이면 도달 상한 `e^rev_max = min(e_max, (D_max−Δ_floor)dt/(1−λ))`.
- 타이브레이크: 직전 c′ 우선(ε 경계 히스테리시스 ε_in<ε_out) → c*와의 위상 거리 → 결정적 사전순.
- 리셋: c′ 변경 시 e←0; 전환·커밋 시 e←0, ρ←0.

### 4.5 안전 오버라이드 (사전식 최상위)
`Safe(c) = clearance≥d_safe ∧ TTC≥TTC_min ∧ feasible`. `c* ∉ 𝒮` ⇒ 누적·경화 무시, 사다리: ① 안전 대안 전환 → ② 감속 → ③ 정지·양보. 스래시 가드: 창 W 내 안전 유발 전환 N_thrash회 ⇒ HOLD.

### 4.6 속성
P1 반진동(D_k 평균0·유계분산 가정의 **기대 전환율 상한**, θ*≈2·Δ_floor/(σ_D²·dt)) · P2 전환율 상한 · P3 안전 지배 · P4 기동 완수(ρ 동역학 + 횡 진행률 하한 v_lat,min, 역방향 누적기 봉쇄) · P5 교착 탈출. (정본 증명은 paper_draft.md §4.6.)

### 4.7 노브 목록 (= ablation 축)
Δ_floor, E_0, k_ρ, p, λ, e_max^fwd/e_max^rev · d_safe, TTC_min · W, N_thrash · w_g/w_s/w_e/w_r · σ_front/σ_rear/σ_s · K(관련자 수) · K_cap.

### 4.8 구현
`Nav2` 커스텀 컨트롤러(또는 플래너) 플러그인. gap←costmap/laser, track·ID←사람 추적 노드. 주기 간 상태(라벨·e^fwd·e^rev·ρ·TTL)는 플러그인 멤버로 보존. F-formation 검출은 외부 인지 모듈 가정.

### §4 수정 부기 (2026-07-02, 심사 대응 — 저자 승인)

> 이 부기는 §4의 확정 설계 원문을 소급 수정하지 않고, 이후 판(v0.7)에서 달라진 점만 기록합니다.

- **`e^fwd`(정방향 class 고정용 누적기) 퇴역.** v0.4가 "P4 봉쇄 vs O4 헤드룸" 자기모순 해소를 위해 도입한 정방향 누적기 `e^fwd`는 갱신 법칙이 정의된 적 없고(논문 §4.5 의사코드에 부재), 구현에서도 갱신되지 않는 죽은 상태 변수였으므로 논문 본문(v0.7)에서 제거했습니다. 위 §4.4·§4.7·§4.8의 분리 누적기 서술은 당시 판의 기록으로 보존하되, 정본은 `paper_draft.md`의 단일 누적기 서술입니다.
- **재진술된 조건.** 전환 동역학은 §4.4 통합식의 **단일 도전 누적기** `e^rev`(= 알고리즘 상태 `e`; rev는 "현재 커밋을 뒤집는 도전 증거"라는 역할 표기) 위에서 닫히며, 건전성은 도달 상한 `e^rev_max = min(e_max, (D_max−Δ_floor)dt/(1−λ))`에 대한 양측 조건 **`E_0 < e^rev_max ≤ E_0(1+k_ρ)`** 하나로 요약됩니다 — 하한은 `ρ=0`에서 재량 전환이 가능하다는 가동성(liveness), 상한은 `ρ ≥ ρ̄`에서 번복이 봉쇄된다는 P4 조건.
- **O4 헤드룸 조건의 처리.** `e_max^fwd > E_0(1+k_ρ)` 헤드룸 조건은 철회되었습니다. P2의 전환 간격 하한은 클립과 무관하게 성립하므로(포화는 도달을 늦출 뿐 앞당기지 못함) 헤드룸은 건전성 조건이 아니었고, 그것이 담으려던 건전성은 `e^rev` **가동성 조건**(`e^rev_max > E_0`)으로 재도출되었습니다(논문 §4.9). §4.7 노브 목록의 `e_max^fwd/e_max^rev` 축은 `e_max`(단일 클립 상한) 축으로 읽습니다.

### §4.6 수정 부기 (2026-08-10, 교차모델 적대 심사 대응 — 저자 승인)

> 이 부기도 §4 확정 **설계**를 바꾸지 않습니다. 알고리즘·상태·노브는 그대로이고, P1의 **가정 서술과 증명 논거**만 교정합니다.

- **P1에 유계 범위 가정 `|D_k| ≤ D_max` 명시.** 기존 P1은 가정을 "정상성 · 평균 0 · 유한 분산"으로만 적어 두고 결론에서 **지수** 상한(`P_switch ≤ exp(−θ* E_0)`, Cramér–Lundberg 유추)을 주장했습니다. 지수 상한의 조정계수 `θ*`는 적률생성함수로 정의되므로 **지수 적률 조건**이 필요하고, 유한 분산만으로는 나오지 않습니다. 반례: 중심화된 Student-`t₃`는 세 가정을 모두 만족하지만 꼬리가 다항 감쇠라 `θ*`가 존재하지 않습니다. 이 구멍은 가정을 한 줄 보태면 닫힙니다 — `D_k = J_k(c*_{k−1}) − J_k(c'_k)`이고 `J`는 §4.2에서 `[0,1]`로 정규화되므로 `D_k`는 **구성상 유계**이며, `D_k ≤ D_max`는 이미 P2(§4.7)·P4(§4.8)·도달 상한 `e^rev_max`(§4.8)가 쓰고 있던 바로 그 가정입니다. P1에만 빠져 있었습니다. 유계이면 MGF가 전 구간 유한하므로 `θ*`가 존재하고, Hoeffding 부등식으로도 동형의 지수 상한이 바로 나옵니다.
- **0 클립의 성격 교정 — 흡수벽 → 반사(포화)벽.** 증명 스케치가 하한 클립을 "0-absorbing barrier"라 불렀으나, 클립은 흡수가 아닙니다. `e^rev`는 증분이 비양수인 동안만 0에 머물고 첫 양의 증분에서 0을 떠납니다(논문 자신도 §4.7·§4.8에서 클립을 "지연·차단할 뿐"인 포화로 다룹니다).
- **`E[T_hit] = ∞` 논거 철회.** 위 오분류 위에 세워졌던 "음의 드리프트가 흡수벽에 가두므로 문턱 미도달 표본경로가 양의 확률로 존재하여 기대 도달시간이 무한"이라는 논거는 반사벽에서는 성립하지 않습니다. 가동성 조건 `e^rev_max > E_0`(§4.9) 아래에서 `e^rev`는 유계 상태공간 `[0, e^rev_max]` 위 양재귀 과정이므로 `E_0`를 **거의 확실히** 넘고 `E[T_hit] < ∞`입니다. "기대 전환시간의 유한 하한"이 무의미한 이유는 기대값이 무한해서가 아니라, 설계상 관심 대상이 **희소성의 스케일**(`E[T_hit]`가 `E_0`에 지수적으로 증가)인데 맨 하한은 그 스케일을 전혀 전달하지 못하기 때문입니다.
- **혼합(mixing) 논거 보강.** 자기상관 처리의 (i) 블록 근사는 블록이 유한 지수적률을 가질 때만 지수 꼬리를 복원합니다. 그 적률을 주는 것은 기하 혼합이 아니라 역시 유계 범위 가정입니다.
- **일관성 반영 위치.** 초록 · §1 기여 목록 · §4.6 명제 1과 증명 · 결정론 특수사례 remark · §6 결론 — P1 가정을 재서술하는 5곳 전부.
- **미검증.** 작업 환경에 LaTeX 툴체인이 없어 재컴파일은 못 했습니다. 정적 검사(환경 균형, `\label`/`\ref` 무결성, 매크로 정의, 중괄호 균형)만 통과한 상태이므로 별도 환경에서 컴파일 확인이 필요합니다.

### 헤드라인 축소: P1 → P2 (2026-08-10, 적대 심사 대응 — 저자 결정)

> 위 유계 가정 추가만으로는 P1이 닫히지 않는다는 판정을 받고, **논문이 내세우는 보증을 결정론적 P2로 좁히기로** 결정했습니다. 알고리즘·상태·노브는 여전히 그대로입니다.

- **잔여 결함.** 유계 가정을 넣어도 P1(ii)는 **정상성만으로는 거짓**입니다. 반례: `Z ∈ {−a, +a}`를 시각 0에 한 번 뽑아 모든 `k`에 `D_k = Z`로 두면 엄밀히 정상·평균 0·유한 분산·유계인데, `a > Δ_floor` 가지에서 누적기가 매 주기 상승해 어떤 `E_0`든 유한 주기에 넘고 반대 가지에서는 영원히 못 넘습니다. 즉 `P_switch → 1/2`로 `E_0`에 대한 감쇠가 전혀 없습니다. 원인은 한 번 뽑힌 국면이 영원히 지속되는 것이 정상성 아래 완전히 허용되기 때문이고, 유계성으로는 고쳐지지 않습니다(블록 논거가 쓸 독립 블록이 없음).
- **P1 재서술.** 명제를 두 단으로 나눴습니다. (i) 음의 드리프트와 그로 인한 희소성은 정상성 아래 성립. (ii) **지수 상한은 종속성 조건**(i.i.d., 또는 재생성 블록 분해가 가능한 속도의 기하 α-혼합) **아래에서만** 성립. 반례는 `\ref{rem:dep}` remark로 본문에 실었습니다 — 심사위원이 쓸 반례를 논문이 먼저 제시하는 형태입니다.
- **헤드라인 이전.** 초록 · §1 기여 · §2 gap 주장 · §6 결론 4곳에서 보증 주체를 **P2**(연속 재량 전환 간격의 결정론적 하한, 표본경로마다 성립, `D_k ≤ D_max` 외 분포 가정 없음)로 바꿨습니다. P1(ii)는 "조건부 정교화"로 표기. "provable anti-oscillation" 문구는 전량 제거(잔재 0건 확인).
- **Remark 2 도피구 삭제.** 임의 자기상관에 대한 "even otherwise" 유효계수 대체(장기분산 `Σ Cov(D_0, D_k)`로 `σ_D²`를 갈음)는 철회했습니다. 장기분산은 대편차율을 결정하지 않고, 이 반사 재귀의 최초통과와 잇는 정리도 없습니다. 혼합은 점근 독립성을, 유계성은 적률을 공급하며 **둘 다** 필요하다고 명시.
