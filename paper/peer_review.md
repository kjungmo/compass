# 동료 심사 리포트 — *Commit-and-Cross* (초안 v0.1)

모사 저널 심사. 심사위원 3인이 독립 검토 후, 편집자가 종합하여 결정을 내립니다. 각 심사위원의 권고 등급: **Reject / Major Revision / Minor Revision / Accept**.

-----

## 심사위원 A — 이론·정형성 (Decision Theory / Formal Methods)

**총평.** 결정의 시간 일관성을 누수 증거 누적이라는 단일 식으로 포착하고, 안전을 사전식으로 분리한 설계가 깔끔하며 속성 P1–P5의 정형화 시도가 돋보입니다. 다만 제시된 증명은 가정이 좁고 일부 경계 사례가 누락되어, 현재로서는 "정리"보다 "스케치"에 가깝습니다. 권고: **Major Revision**.

**강점.**
- 마진·드웰·진행 경화를 하나의 갱신식으로 통합한 점은 노브 수를 줄이고 분석을 가능케 하는 좋은 선택입니다.
- 안전의 사전식 지위(P3)는 명확하며 설득력 있습니다.

**주요 우려 (Major).**
1. **P1의 가정이 비현실적으로 강합니다.** "모든 k에 대해 |D_k| ≤ Δ_floor"는 실제 모호 구성에서 성립하지 않습니다. D_k는 0 근방에서 진동하며 간헐적으로 Δ_floor를 넘습니다. 누적기가 간헐 초과를 누수로 거른다는 **확률적/평균적** 진술(예: D_k가 평균 0, 유계 분산일 때 전환 기대 시간 하한)로 재정식화해야 P1이 실질적 의미를 가집니다.
2. **P4의 ρ 단조성 가정이 정당화되지 않았습니다.** 증명은 "궤적 계층이 기동을 실행하면 ρ → 1"을 전제하나, 환경 변화로 로봇이 밀리거나 통로가 좁아지면 ρ가 정체·감소할 수 있습니다. ρ의 동역학을 정의하고, 횡 이동 속도의 하한을 명시해야 "유한 시간" 주장이 성립합니다.
3. **c′의 비유일성·동률 문제.** 두 도전자의 비용이 동률일 때 argmin이 주기 간 흔들리면, c′ ≠ prev_c′ 시 e ← 0 리셋 규칙이 누적기 자체를 교란해 새로운 진동원을 만듭니다. 타이브레이크 규칙(예: 직전 c′ 우선, 또는 c\*와의 거리)을 명시하십시오.
4. **안전 분기의 자체 진동.** P5는 창 W 내 횟수로 상한하나, 창 내부에서의 고빈도 안전 전환 가능성은 남습니다. 안전 사다리가 1단계(전환)에서 떨기보다 곧장 감속으로 떨어지는 이력 조건을 추가 정의하십시오.
5. **정규화의 명시성.** Δ_floor가 비용 단위인데 J 정규화가 시나리오 의존적이면 마진의 의미가 표류합니다. 정규화 절차를 식으로 제시하고 척도 불변성을 보이십시오.

**소소한 점.** λ와 E_th의 상호작용(누수가 임계 도달을 D의 적분이 아니라 **형상**에 의존하게 만듦)에 대한 한 문단의 특성화가 있으면 좋겠습니다. e_max 포화의 역할도 분석에서 빠져 있습니다.

**저자에게 묻습니다.** λ → 1(누수 없음)과 단순 드웰 타이머 버전 사이의 행동 차이를 정량적으로 보여줄 수 있습니까?

## 심사위원 B — 로보틱스 시스템·실험 (Robotics Systems / Empirical)

**총평.** 설계와 ROS2 통합 경로는 현실적이고 구현 가능성이 높아 보입니다. 그러나 **현재 원고에는 실험 결과가 전무합니다([TBD]).** 시스템 논문으로서 결과 없이 평가할 수 없으며, ablation 표는 데이터가 아니라 가설(예상 방향)에 불과합니다. 권고: **Major Revision** (결과가 게이팅 요인).

**강점.**
- Nav2 플러그인으로의 사상이 명확하고, 상태 보존(라벨·e·ρ·TTL)의 구현 위치가 구체적입니다.
- 헤드라인/표준 지표의 이원 구성이 적절합니다.

**주요 우려 (Major).**
1. **결과 부재.** 전체 시뮬레이션 결과와 실로봇 결과를 채워야 하며, 5.5의 표는 측정값으로 대체되어야 합니다. 현 상태로는 주장 검증이 불가능합니다.
2. **시뮬레이터 순환성.** J_social(사회력 기반 비용)과 보행자 시뮬(PedSim/사회력)이 동일 가정을 공유하면, 제안 방법이 시뮬레이터의 반응 모델에 과적합될 위험이 있습니다. sim-to-real 격차 논의와 가능하면 실제 보행자 실험이 필요합니다.
3. **비교군 공정성.** DWB/TEB/MPPI는 독립적 주체가 동일 시나리오에서 튜닝해야 합니다. 튜닝 프로토콜을 명시하지 않으면 "약화된 베이스라인" 비판을 피할 수 없습니다.
4. **실시간성 미검증.** 주기당 지연, class 열거 비용(2^K), 실제 로봇 CPU 예산, 플러그인 동작 주파수가 빠져 있습니다. 실시간 가용성을 측정으로 입증하십시오.
5. **time-to-legible의 미조작화.** 정의가 모호합니다. 관찰자 모델이나 인간 판단 실험 없이는 측정 불가합니다.
6. **일반화.** 로봇 풋프린트·구동 방식(차동/전방향)·센서 구성 변화에 대한 일반화가 논의되지 않았습니다.

**소소한 점.** 실로봇 시행 수 N과 환경 다양성을 명기하십시오. 실패 사례(collision/near-miss)의 정성 분석이 있으면 설득력이 큽니다.

**저자에게 묻습니다.** 실제 로봇에서 한 주기 결정 루프의 최악 지연은 얼마이며, K가 커질 때(혼잡) 어떻게 경계됩니까?

## 심사위원 C — 사회적 내비게이션·HRI (Social Navigation / Human Factors)

**총평.** "읽히는 로봇"이라는 동기와 커밋–가독성 연결은 매력적입니다. 그러나 가독성·사회적 적절성 주장이 인간 데이터로 뒷받침되지 않고, 사회 비용의 파라미터·관습 가정이 보편으로 제시되어 문화적·맥락적 타당성이 의심됩니다. 권고: **Major Revision** (경계선).

**강점.**
- 비대칭 proxemics를 결정에 직접 연결한 점, 그리고 정지를 가독적 폴백으로 본 관점이 좋습니다.

**주요 우려 (Major).**
1. **가독성의 인간 검증 부재.** legibility를 기여로 내세우면서 사용자 연구가 없습니다. time-to-legible은 프록시일 뿐이며, 최소한 지각 실험(영상 기반 판단)으로 "사람이 통과 측을 더 빨리·정확히 예측하는가"를 보여야 합니다.
2. **proxemics 파라미터의 근거.** σ_front, σ_rear, σ_s는 경험적 근거·인용이 필요하며 문화 의존적일 수 있습니다. 우측 통행과 후방 통과 선호를 보편으로 가정했는데, 한국·동아시아 보행 규범은 다를 수 있습니다. 근거를 제시하거나 설정 가능하게 하고 민감도를 평가하십시오.
3. **"후방 통과"의 사회적 바람직성.** 사람의 사각(뒤)에서 접근·통과하는 것은 상황에 따라 놀람·불편을 유발합니다. 후방 vs 전방 통과의 적절성은 맥락 의존적이므로 무조건적 선호는 정당화가 필요합니다.
4. **군집·F-formation.** 대화 중인 그룹은 가르지 말아야 하는데, 병합 규칙이 공간 근접에만 기반하면 사회적 그룹(상호작용 기반)을 놓칩니다. 처리 방안을 논의하십시오.
5. **관련 연구 보강.** HRI 내비게이션(의도 인지 계획, social momentum, 인간 쾌적성 지표)과 보행자 궤적 예측 문헌이 빠져 있습니다.

**소소한 점.** 취약 보행자(아동·고령자·휠체어) 근처에서의 커밋·안전 여유에 대한 윤리·쾌적성 고려가 한 절 있으면 좋겠습니다.

**저자에게 묻습니다.** 우측 통행 가정이 거짓인 환경(혹은 좌측 통행 문화)에서 성능이 어떻게 저하됩니까? J_rule 가중치에 대한 민감도 곡선이 있습니까?

## 편집자 종합 의견 (Editor's Meta-Review)

**결정: Major Revision.**

세 심사위원 모두 설계의 신규성·명료성을 인정하나, 독립적으로 동일한 두 축의 약점을 지적했습니다 — **(가) 경험적 검증의 부재**와 **(나) 사회·가독성 주장의 인간 데이터 부재**. 이를 중심으로 필수 수정을 우선순위화합니다.

**합의된 핵심 쟁점 (2인 이상 공통):**
- **결과 채우기.** A(ablation이 추정), B(결과 전무) 공통. 5.5의 가설 표를 측정 데이터로 대체하고, 비모수 검정·효과 크기·시드/시행 수를 보고.
- **가독성·사회 주장의 인간 근거.** B(time-to-legible 미조작화) + C(사용자 연구 필요) 공통. 지각/사용자 실험을 추가하거나, 주장의 범위를 명시적으로 축소.
- **가정의 정당화.** A(정규화 표류) + C(proxemics·관습 보편화) 공통. 파라미터를 설정 가능하게 하고 민감도 분석 추가.
- **정형 주장의 엄밀화.** A 단독이나 중대 — P1을 평균적/유계 분산 진술로 재정식화, P4의 ρ 동역학·횡 속도 하한 명시, c′ 타이브레이크와 안전 분기 자체 이력 추가.

**필수 수정 (Required):**
- **R1.** 전체 시뮬레이션 + 실로봇 결과를 채우고 ablation 표를 데이터로 교체. (B1, A1)
- **R2.** 비교군 튜닝 프로토콜을 독립 주체 기준으로 명시. (B3)
- **R3.** 실시간성·열거 비용(2^K)·주기 지연을 측정으로 보고. (B4, B-질문)
- **R4.** time-to-legible을 관찰자 모델 또는 인간 판단으로 조작화하고, 최소 지각 실험 추가. (B5, C1)
- **R5.** proxemics·관습 파라미터의 근거·설정 가능성·민감도 분석 추가(문화 의존성 포함). (C2, C3, A5)
- **R6.** P1·P4 재정식화, c′ 타이브레이크 규칙, 안전 분기 이력 추가. (A1, A2, A3, A4)

**권장 개선 (Optional):**
- **O1.** sim-to-real 격차 논의 및 가능하면 실제 보행자 실험. (B2)
- **O2.** 군집/F-formation 처리와 취약 보행자 고려 절. (C4, C-소소)
- **O3.** HRI·예측 문헌으로 관련 연구 보강. (C5)
- **O4.** λ vs 단순 드웰 비교, e_max 포화 분석. (A-소소, A-질문)

**편집자 코멘트.** 핵심 아이디어(통과 결정의 시간 일관성)는 분명한 공백을 메우며 기여로서 충분히 가치가 있습니다. 게재 가능성을 가르는 것은 아이디어가 아니라 **증거**입니다. R1·R4·R5를 충실히 채우면 강한 논문이 될 것으로 판단합니다.
